# Campus Events (Human-Machine-Interface-Design-LAB1)

## Project Name
Campus Events (Система управления кампусными мероприятиями и регистрацией)

## Description
Платформа для управления кампусными мероприятиями и регистрацией участников. Система поддерживает публикацию мероприятий, онлайн-регистрацию в один клик, QR-регистрацию на месте и автоматическую аналитику посещаемости. Проект включает веб-админку для организаторов и мобильное приложение для студентов.

## Installation
Для локального запуска проекта выполните следующие шаги:
1. Клонируйте основной репозиторий: `git clone https://github.com/1997yyyy/Human-Machine-Interface-Design-LAB1.git`
2. Перейдите в каталог проекта: `cd Human-Machine-Interface-Design-LAB1`
3. Установите необходимые зависимости (для Web-части): `pip install -r requirements.txt`
4. Примените миграции базы данных: `python manage.py migrate`
5. Запустите сервер разработки: `python manage.py runserver`

## Usage
После установки и запуска сервера откройте браузер по адресу `http://localhost:8000`. 
- Для доступа к панели администратора перейдите по адресу `/admin`.
- Мобильное приложение подключается к API по адресу `http://localhost:8000/api/`.
